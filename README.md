# E-Commerce Platform Performance Analytics Dashboard 📊

An interactive data analytics project designed to analyze and compare the performance of online shopping platforms using **Python, SQL, Pandas, Streamlit, and Plotly**.

The dashboard provides insights into **sales, revenue, customer satisfaction, returns, and inventory/stock availability** across different e-commerce platforms.

### 🔍 Key Analysis

* 📦 Total orders and products sold
* 💰 Revenue and Average Order Value (AOV)
* 📈 Monthly and yearly sales/revenue trends
* 🛒 Platform-wise sales and revenue comparison
* ⭐ Customer satisfaction and average ratings
* 🔄 Return rate and return-reason analysis
* 📊 Revenue contribution by platform
* 📦 Stock availability and stock-out analysis
* 🔎 Interactive platform and year filters

### 🛠️ Technologies Used

* **Python** – Data cleaning and analysis
* **Pandas** – Data manipulation and analysis
* **SQL** – Database design and analytical queries
* **Streamlit** – Interactive dashboard
* **Plotly** – Data visualization
* **Git & GitHub** – Version control and project management

### 🎯 Business Questions

The project aims to answer questions such as:

* Which platform generates the most revenue?
* Which platform sells the most products?
* How do customer ratings differ across platforms?
* Which platforms have higher return rates?
* What are the major reasons for product returns?
* Which platforms experience more stock issues?
* How does revenue change over time?

### 🚀 How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run dashboard/ecommerce_dashboard.py
```
